# Кадры

Редактируемая карта сотрудников и подразделений на shadcn/ui.

Рабочий сайт: https://rgpu-staff-map.surepony8.chatgpt.site

Это резервная копия кода. Фамилии, ставки, текущая карта и её содержимое не публикуются в репозитории. Данные рабочего сайта сохраняются отдельно в приватной базе D1.

## Возможности

- Карточки сотрудников, цветные круги подразделений и их значки в карточках.
- Перемещение карточек, связи со стрелками, заметки и поиск.
- Общее серверное сохранение, обновления между устройствами и защита от перезаписи одновременных правок.
- Локальная очередь при потере сети, экспорт и импорт JSON.

## Сборка

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run build
node --test tests/shared-state.test.mjs
```

В этом публичном исходнике начальная карта содержит только подразделения. Сотрудники создаются в редакторе либо загружаются импортом после настройки приватного хранилища.

## Размещение

Приложение использует Vinext, Cloudflare Workers и D1. Миграции лежат в `drizzle/`, привязка базы — `DB`. Для публикации через Sites нужно привязать проект в `.openai/hosting.json`. Сама база и её данные в код не входят.

GitHub Pages без отдельного сервера не поддерживает общее сохранение этой карты. Работающая публикация остаётся по ссылке выше. Репозиторий сам по себе не является резервной копией данных; их можно выгружать кнопкой «Экспорт JSON».

API `/api/state` рассчитан на приватную публикацию, где платформа проверяет доступ к каждому запросу. Не открывайте его публично без отдельной серверной авторизации. Для входа с другого устройства используйте тот же аккаунт, которому разрешён доступ к рабочему сайту.

## Компоненты

Card, Badge, Button, Input и Textarea взяты из официального реестра shadcn/ui; иконки — Lucide. Лицензия shadcn/ui приложена в `SHADCN-LICENSE.md`.
